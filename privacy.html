gog-cli プライバシーポリシー / Privacy Policy

最終更新日：2026年11月6日 / Last updated: November 6, 2026

1. 取得する情報

gog-cli は、利用者が許可した範囲で、その利用者自身の Google アカウントのデータ（Google スプレッドシートの内容など）にアクセスします。

2. 使い方

取得したデータは、利用者自身のパソコンの上で、利用者が実行したコマンドの処理にだけ使います。広告、分析、販売には使いません。

3. 保存と第三者への提供

データや認証情報は利用者自身のパソコンにだけ保存され、開発者のサーバーへ送ることはありません。第三者へ提供・共有・販売することはありません。

4. Google API サービスのユーザーデータポリシー

Google API から受け取った情報の使用と他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

5. アクセスの取り消し

利用者は Google アカウントのサードパーティ アクセスの設定 から、いつでもアクセスを取り消せます。

6. お問い合わせ

GitHub の Issues からご連絡ください。

gog-cli accesses data in the user's own Google account (such as Google Sheets) only as authorized by the user. The data is used only on the user's own computer to run the commands the user executes. It is not sent to the developer's servers, and it is not shared with or sold to third parties. gog-cli's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from Google Account third-party access settings. Contact: GitHub Issues of this repository.
